# pd-review-kata

Учебный репозиторий курса «Проектная деятельность» (ПД ТОП-ИТ), пара 11 «Работающий инкремент».

Команда делает сервис записи студентов на консультации к преподавателю. В `main` лежит рабочая основа: слоты и хранение записей в JSON-файле. Всё остальное приходит через pull request, и ваша задача — эти PR проверить.

## Что есть в репозитории

| PR | Что это |
|---|---|
| [#1](../../pull/1) | Общий пример: большой PR новичка, разбираем вместе |
| [#2](../../pull/2) – [#8](../../pull/8) | Задания: каждой команде свой PR |
| [#9](../../pull/9) – [#13](../../pull/13) | Примеры ревью: один и тот же код и пять разных ревьюеров |

## Задание: ревью своего PR

Номер PR = номер команды + 1.

| Команда | PR | Что добавляет |
|---|---|---|
| 1 | [#2](../../pull/2) | отмена записи |
| 2 | [#3](../../pull/3) | напоминания |
| 3 | [#4](../../pull/4) | экспорт в CSV |
| 4 | [#5](../../pull/5) | проверка ввода |
| 5 | [#6](../../pull/6) | статистика по слотам |
| 6 | [#7](../../pull/7) | лист ожидания |
| 7 | [#8](../../pull/8) | команды преподавателя |

1. Откройте свой PR и вкладку **Files changed**. Загляните и во вкладку **Commits**.
2. За 8 минут найдите как можно больше проблем. Смотрите на код, на описание PR и на то, чего в PR не хватает.
3. Каждое замечание запишите строкой в таблицу своей команды на доске:

```
<пометка> | <файл>:<строка> | <что не так и что предлагаете>
```

Пометки:

| Пометка | Когда ставить |
|---|---|
| `issue` | надо исправить до слияния |
| `suggestion` | можно сделать лучше, предлагаю как |
| `question` | не понимаю решение, спрашиваю о причине |
| `nitpick` | мелочь, слияние не блокирует |
| `praise` | хорошо сделано, стоит повторять |

Пример из другого проекта: `issue | bot/handlers.py:17 | функция на 120 строк, предлагаю разбить на три`

## Как засчитывается

- В каждом PR-задании заложено 8 проблем. 1 балл за каждую, если указаны место и суть.
- «Плохой код» или «переписать» без объяснения не засчитывается.
- 1 балл за уместный `praise`: в каждом PR есть и хорошие решения.
- 1 балл за проблему, которой нет в ключе, если она по делу.

## Примеры ревью

В PR #9–#13 код одинаковый, а комментарии оставили пять разных ревьюеров: хороший, грубый, зануда, тот, кто тянет время, и тот, кто пишет не по сути. В коде три настоящие проблемы. Посмотрите, кто из ревьюеров их нашёл и чьи комментарии помогли бы автору.
