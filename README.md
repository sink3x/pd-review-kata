# pd-review-kata

Учебный репозиторий курса «Проектная деятельность» (ПД ТОП-ИТ), пара 11 «Работающий инкремент».

Команда делает сервис записи студентов на консультации к преподавателю. В `main` лежит рабочая основа: слоты и хранение записей в JSON-файле.

## Задание: ревью PR

Новый участник команды открыл pull request **#1** и просит его влить. Вы ревьюеры.

1. Откройте PR и вкладку **Files changed**.
2. За 8 минут найдите как можно больше проблем. Смотрите на код, на описание PR и на то, что в PR отсутствует.
3. Каждое замечание запишите одной строкой по образцу:

```
<пометка> | <файл>:<строка> | <что не так и что предлагаете>
```

Пометки:

| Пометка | Когда ставить |
|---|---|
| `issue` | надо исправить до слияния |
| `suggestion` | можно сделать лучше, предлагаю как |
| `question` | не понимаю решение, спрашиваю о причине |
| `nitpick` | мелочь, слияние не блокирует |
| `praise` | хорошо сделано, стоит повторять |

Пример из другого проекта: `issue | bot/handlers.py:17 | функция на 120 строк, предлагаю разбить на три`

Замечания пишите в своём листе команды, а не в комментариях к PR: другие команды не должны видеть ваши находки.

## Как засчитывается

- 1 балл за каждую найденную проблему из ключа преподавателя, если указаны место и суть.
- «Плохой код» или «переписать» без объяснения не засчитывается.
- 1 балл за уместный `praise`: в PR есть и хорошие решения.

## Запуск

Нужен Python 3.10+, зависимостей нет.

```bash
python -m unittest discover -s tests -v
```
